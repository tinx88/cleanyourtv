# Sony BRAVIA XR-65X90J

Target device for first validation. The TV's LAN address is deliberately not
stored in this public repository.

- Back up packages, disabled packages, system settings and properties first.
- Protect HDMI-CEC, input switcher, Bluetooth, remote app buttons, casting,
  Google services, tuner and firmware updates.
- Identify device-specific bloat; do not use another Sony model's list blindly.
- Install and verify the launcher before disabling stock Home.
- Test real remote buttons; use a reversible restore record stored locally.
- Disable debugging and revoke ADB authorisations afterwards.
